# auth-bff Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `auth-bff` service that owns the Keycloak OIDC flow and writes the server-side session contract to Redis, so the browser holds only an opaque `HttpOnly` cookie and never a JWT.

**Architecture:** Hexagonal Kotlin service (`domain / application / infrastructure / bootstrap` Gradle modules). Spring Security's `oauth2Login` performs the authorization code flow with PKCE; a custom success handler mints an opaque session id, encrypts the refresh and ID tokens, and writes the `v1:session:{sid}` hash to Redis. Refresh and revocation are exposed as HTTP endpoints. This service is the **only writer** to the Redis contract; the gateway plugin (separate plan) is a reader.

**Tech Stack:** Kotlin 2.2.21, Spring Boot 4.0.0, Spring Security 7 (`oauth2-client`), Lettuce via `spring-boot-starter-data-redis`, Jackson 3, JUnit 5, MockK 1.13.17, Testcontainers 1.21.4, ArchUnit 1.4.2.

**Spec:** `docs/superpowers/specs/2026-08-31-token-handler-bff-design.md` (in the `krakend-gateway` repo)

**Repository:** This plan builds a **new** repository, `codehunters/auth-bff`. The plan document itself lives in `krakend-gateway` because that is where the spec lives; all paths below are relative to the new repo's root unless stated otherwise.

## Global Constraints

- Kotlin `2.2.21`, JVM target `21`, `allWarningsAsErrors = true`.
- Spring Boot `4.0.0`; Jackson 3 — use `JsonMapper`, never `ObjectMapper`.
- `:domain` has zero framework dependencies. `:application` depends only on `:domain` and carries no Spring annotations.
- Redis key prefix is `v1:`. The field names in `v1:session:{sid}` are fixed by the spec and are a cross-repository contract: `ver, sub, kc_sid, access_token, exp, abs_exp, refresh_token_enc, id_token_enc, created_at`. Changing any name breaks the gateway plugin.
- `sid` is 32 random bytes rendered as unpadded base64url — exactly 43 characters.
- Idle TTL 1800s, absolute session lifetime 36000s (10h). Both are configuration, not constants in code.
- Never log a `sid`, an access token, a refresh token, an ID token, or a logout token.
- Package root: `io.codehunters.authbff`.
- Service port: `8086`.

```kotlin
package io.codehunters.authbff.session

/**
 * Opaque session identifier handed to the browser. It is a bearer credential:
 * never log it, never derive it from token claims.
 */
@JvmInline
value class SessionId private constructor(val value: String) {

    companion object {
        private const val LENGTH = 43
        private val FORMAT = Regex("^[A-Za-z0-9_-]{$LENGTH}$")

        fun of(raw: String): SessionId {
            require(FORMAT.matches(raw)) {
                "session id must be $LENGTH base64url characters"
            }
            return SessionId(raw)
        }
    }
}
```

```kotlin
package io.codehunters.authbff.session

import java.time.Duration
import java.time.Instant

data class Session(
    val id: SessionId,
    val subject: String,
    val keycloakSessionId: String,
    val tokens: TokenBundle,
    val absoluteExpiresAt: Instant,
    val createdAt: Instant,
) {
    init {
        require(subject.isNotBlank()) { "subject must not be blank" }
        require(absoluteExpiresAt.isAfter(createdAt)) {
            "absolute expiry must be after creation"
        }
    }

    fun needsRefresh(now: Instant, threshold: Duration): Boolean =
        !now.isBefore(tokens.expiresAt.minus(threshold))

    fun isAbsolutelyExpired(now: Instant): Boolean = !now.isBefore(absoluteExpiresAt)

    fun withTokens(newTokens: TokenBundle): Session = copy(tokens = newTokens)
}
```

```kotlin
package io.codehunters.authbff.session.usecase

import io.codehunters.authbff.session.Session
import io.codehunters.authbff.session.SessionId
import io.codehunters.authbff.session.TokenBundle
import io.codehunters.authbff.session.port.ClockPort
import io.codehunters.authbff.session.port.SessionIdGeneratorPort
import io.codehunters.authbff.session.port.SessionStorePort
import java.time.Duration

data class CreateSessionCommand(
    val subject: String,
    val keycloakSessionId: String,
    val tokens: TokenBundle,
)

class CreateSession(
    private val store: SessionStorePort,
    private val clock: ClockPort,
    private val sessionIds: SessionIdGeneratorPort,
    private val absoluteLifetime: Duration,
) {
    fun execute(command: CreateSessionCommand): SessionId {
        val createdAt = clock.now()
        val session = Session(
            id = sessionIds.generate(),
            subject = command.subject,
            keycloakSessionId = command.keycloakSessionId,
            tokens = command.tokens,
            absoluteExpiresAt = createdAt.plus(absoluteLifetime),
            createdAt = createdAt,
        )
        store.save(session)
        return session.id
    }
}
```

```kotlin
package io.codehunters.authbff.crypto

import java.security.SecureRandom
import java.util.Base64
import javax.crypto.Cipher
import javax.crypto.spec.GCMParameterSpec
import javax.crypto.spec.SecretKeySpec

/**
 * Encrypts refresh and ID tokens at rest. Values are encoded as
 * `<keyId>.<base64url(iv)>.<base64url(ciphertext)>` so a retired key can still
 * decrypt existing sessions while new writes use the active key.
 */
class AesGcmTokenCipher(
    private val keys: Map<String, ByteArray>,
    private val activeKeyId: String,
) : TokenCipher {

    private val random = SecureRandom()
    private val encoder: Base64.Encoder = Base64.getUrlEncoder().withoutPadding()
    private val decoder: Base64.Decoder = Base64.getUrlDecoder()

    init {
        require(keys.isNotEmpty()) { "at least one cipher key is required" }
        require(keys.containsKey(activeKeyId)) { "active key id is not present in the key set" }
        keys.forEach { (id, key) ->
            require(key.size == KEY_BYTES) { "key '$id' must be $KEY_BYTES bytes" }
        }
    }

    override fun encrypt(plain: String): String {
        val iv = ByteArray(IV_BYTES).also(random::nextBytes)
        val cipher = Cipher.getInstance(TRANSFORMATION).apply {
            init(Cipher.ENCRYPT_MODE, keySpec(activeKeyId), GCMParameterSpec(TAG_BITS, iv))
        }
        val encrypted = cipher.doFinal(plain.toByteArray())
        return "$activeKeyId.${encoder.encodeToString(iv)}.${encoder.encodeToString(encrypted)}"
    }

    override fun decrypt(encoded: String): String {
        val parts = encoded.split('.')
        require(parts.size == 3) { "malformed ciphertext" }
        val (keyId, iv, payload) = parts
        require(keys.containsKey(keyId)) { "unknown cipher key id" }

        val cipher = Cipher.getInstance(TRANSFORMATION).apply {
            init(Cipher.DECRYPT_MODE, keySpec(keyId), GCMParameterSpec(TAG_BITS, decoder.decode(iv)))
        }
        return String(cipher.doFinal(decoder.decode(payload)))
    }

    private fun keySpec(keyId: String) = SecretKeySpec(keys.getValue(keyId), "AES")

    private companion object {
        const val TRANSFORMATION = "AES/GCM/NoPadding"
        const val KEY_BYTES = 32
        const val IV_BYTES = 12
        const val TAG_BITS = 128
    }
}
```

```kotlin
package io.codehunters.authbff.redis

import io.codehunters.authbff.crypto.TokenCipher
import io.codehunters.authbff.session.Session
import io.codehunters.authbff.session.SessionId
import io.codehunters.authbff.session.TokenBundle
import io.codehunters.authbff.session.port.SessionStorePort
import java.time.Duration
import java.time.Instant
import org.springframework.data.redis.core.StringRedisTemplate

class RedisSessionStoreAdapter(
    private val redis: StringRedisTemplate,
    private val cipher: TokenCipher,
    private val keyPrefix: String,
    private val idleTtl: Duration,
) : SessionStorePort {

    override fun save(session: Session) {
        val key = sessionKey(session.id)
        redis.opsForHash<String, String>().putAll(
            key,
            mapOf(
                SessionFields.VERSION to SessionFields.SCHEMA_VERSION,
                SessionFields.SUBJECT to session.subject,
                SessionFields.KEYCLOAK_SESSION_ID to session.keycloakSessionId,
                SessionFields.ACCESS_TOKEN to session.tokens.accessToken,
                SessionFields.EXPIRES_AT to session.tokens.expiresAt.epochSecond.toString(),
                SessionFields.ABSOLUTE_EXPIRES_AT to session.absoluteExpiresAt.epochSecond.toString(),
                SessionFields.REFRESH_TOKEN to cipher.encrypt(session.tokens.refreshToken),
                SessionFields.ID_TOKEN to cipher.encrypt(session.tokens.idToken),
                SessionFields.CREATED_AT to session.createdAt.epochSecond.toString(),
            ),
        )
        redis.expire(key, idleTtl)

        val index = keycloakIndexKey(session.keycloakSessionId)
        redis.opsForValue().set(index, session.id.value, idleTtl)
    }

    override fun findById(id: SessionId): Session? {
        val hash = redis.opsForHash<String, String>().entries(sessionKey(id))
        if (hash.isEmpty()) return null

        return Session(
            id = id,
            subject = hash.getValue(SessionFields.SUBJECT),
            keycloakSessionId = hash.getValue(SessionFields.KEYCLOAK_SESSION_ID),
            tokens = TokenBundle(
                accessToken = hash.getValue(SessionFields.ACCESS_TOKEN),
                refreshToken = cipher.decrypt(hash.getValue(SessionFields.REFRESH_TOKEN)),
                idToken = cipher.decrypt(hash.getValue(SessionFields.ID_TOKEN)),
                expiresAt = hash.getValue(SessionFields.EXPIRES_AT).toInstant(),
            ),
            absoluteExpiresAt = hash.getValue(SessionFields.ABSOLUTE_EXPIRES_AT).toInstant(),
            createdAt = hash.getValue(SessionFields.CREATED_AT).toInstant(),
        )
    }

    override fun delete(id: SessionId) {
        val kcSid = redis.opsForHash<String, String>()
            .get(sessionKey(id), SessionFields.KEYCLOAK_SESSION_ID)
        redis.delete(sessionKey(id))
        if (kcSid != null) redis.delete(keycloakIndexKey(kcSid))
    }

    override fun findIdByKeycloakSessionId(kcSid: String): SessionId? =
        redis.opsForValue().get(keycloakIndexKey(kcSid))?.let(SessionId::of)

    override fun claimLogoutToken(jti: String, ttl: Duration): Boolean =
        redis.opsForValue().setIfAbsent("${keyPrefix}logout_jti:$jti", "1", ttl) == true

    private fun sessionKey(id: SessionId) = "${keyPrefix}session:${id.value}"

    private fun keycloakIndexKey(kcSid: String) = "${keyPrefix}kcsid:$kcSid"

    private fun String.toInstant(): Instant = Instant.ofEpochSecond(toLong())
}
```

```kotlin
package io.codehunters.authbff.keycloak

import io.codehunters.authbff.session.TokenBundle
import io.codehunters.authbff.session.port.ClockPort
import io.codehunters.authbff.session.port.IdentityProviderPort
import java.net.URLEncoder
import java.nio.charset.StandardCharsets
import org.springframework.http.MediaType
import org.springframework.util.LinkedMultiValueMap
import org.springframework.web.client.RestClient
import org.springframework.web.client.RestClientException

data class KeycloakEndpointConfig(
    val tokenUri: String,
    val endSessionUri: String,
    val clientId: String,
    val clientSecret: String,
    val postLogoutRedirectUri: String,
)

class RefreshFailedException(cause: Throwable) :
    RuntimeException("refresh token exchange failed", cause)

class KeycloakIdentityProviderAdapter(
    private val restClient: RestClient,
    private val clock: ClockPort,
    private val config: KeycloakEndpointConfig,
) : IdentityProviderPort {

    override fun refresh(refreshToken: String): TokenBundle {
        val form = LinkedMultiValueMap<String, String>().apply {
            add("grant_type", "refresh_token")
            add("refresh_token", refreshToken)
            add("client_id", config.clientId)
            add("client_secret", config.clientSecret)
        }

        val response = try {
            restClient.post()
                .uri(config.tokenUri)
                .contentType(MediaType.APPLICATION_FORM_URLENCODED)
                .body(form)
                .retrieve()
                .body(TokenResponse::class.java)
        } catch (e: RestClientException) {
            throw RefreshFailedException(e)
        } ?: throw RefreshFailedException(IllegalStateException("empty token response"))

        return TokenBundle(
            accessToken = response.accessToken,
            refreshToken = response.refreshToken,
            idToken = response.idToken,
            expiresAt = clock.now().plusSeconds(response.expiresIn),
        )
    }

    override fun endSessionUrl(idToken: String): String {
        val hint = encode(idToken)
        val redirect = encode(config.postLogoutRedirectUri)
        return "${config.endSessionUri}?id_token_hint=$hint&post_logout_redirect_uri=$redirect"
    }

    private fun encode(value: String) = URLEncoder.encode(value, StandardCharsets.UTF_8)
}
```

```kotlin
package io.codehunters.authbff.session.usecase

import io.codehunters.authbff.session.SessionId
import io.codehunters.authbff.session.port.ClockPort
import io.codehunters.authbff.session.port.IdentityProviderPort
import io.codehunters.authbff.session.port.SessionStorePort

class SessionNotFoundException : RuntimeException("session not found")

class SessionExpiredException : RuntimeException("session past its absolute expiry")

class RefreshSession(
    private val store: SessionStorePort,
    private val identityProvider: IdentityProviderPort,
    private val clock: ClockPort,
) {
    fun execute(id: SessionId): String {
        val session = store.findById(id) ?: throw SessionNotFoundException()

        if (session.isAbsolutelyExpired(clock.now())) {
            store.delete(id)
            throw SessionExpiredException()
        }

        val refreshed = session.withTokens(identityProvider.refresh(session.tokens.refreshToken))
        store.save(refreshed)
        return refreshed.tokens.accessToken
    }
}
```

```kotlin
package io.codehunters.authbff.web

import io.codehunters.authbff.session.SessionId
import java.time.Duration
import org.springframework.http.ResponseCookie

/**
 * The cookie name is configuration, not a constant: the `__Host-` prefix requires
 * HTTPS and is rejected by browsers over plain http, which is how the gateway runs
 * locally. Production sets `__Host-sid`, local development sets `sid`.
 */
class SessionCookieFactory(
    private val name: String,
    private val secure: Boolean,
    private val idleTtl: Duration,
) {
    fun issue(sid: SessionId): ResponseCookie = base(sid.value).maxAge(idleTtl).build()

    fun expire(): ResponseCookie = base("").maxAge(Duration.ZERO).build()

    private fun base(value: String) = ResponseCookie.from(name, value)
        .httpOnly(true)
        .secure(secure)
        .sameSite("Lax")
        .path("/")
}
```

```kotlin
import io.codehunters.authbff.session.TokenBundle
import io.codehunters.authbff.session.usecase.CreateSession
import io.codehunters.authbff.session.usecase.CreateSessionCommand

import jakarta.servlet.http.HttpServletRequest
import jakarta.servlet.http.HttpServletResponse
import org.slf4j.LoggerFactory
import org.springframework.http.HttpHeaders
import org.springframework.security.core.Authentication
import org.springframework.security.oauth2.client.OAuth2AuthorizedClientService
import org.springframework.security.oauth2.client.authentication.OAuth2AuthenticationToken
import org.springframework.security.oauth2.core.oidc.user.OidcUser
import org.springframework.security.web.authentication.AuthenticationSuccessHandler

/**
 * Turns a completed authorization code flow into a server-side session. The tokens
 * go to Redis; the browser receives only the opaque session id.
 */
class SessionSuccessHandler(
    private val createSession: CreateSession,
    private val authorizedClients: OAuth2AuthorizedClientService,
    private val cookies: SessionCookieFactory,
    private val frontendUrl: String,
) : AuthenticationSuccessHandler {

    private val log = LoggerFactory.getLogger(javaClass)

    override fun onAuthenticationSuccess(
        request: HttpServletRequest,
        response: HttpServletResponse,
        authentication: Authentication,
    ) {
        val token = authentication as OAuth2AuthenticationToken
        val user = token.principal as OidcUser
        val client = authorizedClients.loadAuthorizedClient<org.springframework.security.oauth2.client.OAuth2AuthorizedClient>(
            token.authorizedClientRegistrationId,
            token.name,
        )

        val sid = createSession.execute(
            CreateSessionCommand(
                subject = user.subject,
                keycloakSessionId = user.claims["sid"]?.toString().orEmpty(),
                tokens = TokenBundle(
                    accessToken = client.accessToken.tokenValue,
                    refreshToken = requireNotNull(client.refreshToken) {
                        "Keycloak returned no refresh token; check the client's scope"
                    }.tokenValue,
                    idToken = user.idToken.tokenValue,
                    expiresAt = requireNotNull(client.accessToken.expiresAt),
                ),
            )
        )

        // Session fixation: the login-time servlet session dies here.
        request.getSession(false)?.invalidate()

        // Never log sid, tokens, or claims beyond the subject.
        log.info("session created sub={}", user.subject)

        response.addHeader(HttpHeaders.SET_COOKIE, cookies.issue(sid).toString())
        response.sendRedirect(frontendUrl)
    }
}
```

```kotlin
package io.codehunters.authbff.config

import org.springframework.context.annotation.Bean
import org.springframework.context.annotation.Configuration
import org.springframework.security.config.annotation.web.builders.HttpSecurity
import org.springframework.security.web.SecurityFilterChain
import org.springframework.security.web.authentication.AuthenticationSuccessHandler

@Configuration
class SecurityConfig {

    /**
     * `oauth2Login` owns state, PKCE and nonce. Everything else is unauthenticated at
     * the Spring level: `/auth/session`, `/auth/logout` and `/internal/*` authenticate
     * against Redis or the internal shared secret, not against a servlet principal.
     */
    @Bean
    fun filterChain(
        http: HttpSecurity,
        successHandler: AuthenticationSuccessHandler,
    ): SecurityFilterChain {
        http
            .csrf { it.disable() }
            .authorizeHttpRequests { auth ->
                auth.requestMatchers(
                    "/auth/session",
                    "/auth/logout",
                    "/auth/backchannel-logout",
                    "/internal/**",
                    "/actuator/health",
                    "/actuator/health/**",
                ).permitAll()
                auth.anyRequest().authenticated()
            }
            .oauth2Login { login ->
                // Spring's defaults are /oauth2/authorization/{id} and /login/oauth2/code/{id}.
                // The gateway only exposes /auth/*, and the browser never talks to this service
                // directly, so both endpoints move under that prefix. Public login URL becomes
                // /auth/login/keycloak; the callback is a fixed /auth/callback (the registration
                // is resolved from the `state` parameter, so it needs no {registrationId}).
                login.authorizationEndpoint { it.baseUri("/auth/login") }
                login.redirectionEndpoint { it.baseUri("/auth/callback") }
                login.successHandler(successHandler)
            }
        return http.build()
    }
}
```

CSRF is disabled here deliberately: this service has no cookie-authenticated state-changing form, and the browser-facing CSRF defense lives in the gateway plugin (`Origin` validation) plus `SameSite=Lax`. `/internal/**` is protected by the shared secret added in Task 8.

```kotlin
package io.codehunters.authbff.web

import io.codehunters.authbff.session.SessionId
import io.codehunters.authbff.session.usecase.RefreshSession
import io.codehunters.authbff.session.usecase.SessionExpiredException
import io.codehunters.authbff.session.usecase.SessionNotFoundException
import org.springframework.http.HttpStatus
import org.springframework.http.ResponseEntity
import org.springframework.web.bind.annotation.PathVariable
import org.springframework.web.bind.annotation.PostMapping
import org.springframework.web.bind.annotation.RequestHeader
import org.springframework.web.bind.annotation.RequestMapping
import org.springframework.web.bind.annotation.ResponseBody

data class RefreshResponse(val access_token: String)

/**
 * Called only by the gateway's session-resolver plugin. Network isolation is not an
 * access control, so the shared secret is mandatory.
 */
@ResponseBody
@RequestMapping("/internal/sessions")
class InternalRefreshController(
    private val refreshSession: RefreshSession,
    private val sharedSecret: String,
) {
    @PostMapping("/{sid}/refresh")
    fun refresh(
        @PathVariable sid: String,
        @RequestHeader(value = "X-Internal-Secret", required = false) secret: String?,
    ): ResponseEntity<RefreshResponse> {
        if (secret == null || !constantTimeEquals(secret, sharedSecret)) {
            return ResponseEntity.status(HttpStatus.UNAUTHORIZED).build()
        }

        val sessionId = runCatching { SessionId.of(sid) }.getOrNull()
            ?: return ResponseEntity.status(HttpStatus.UNAUTHORIZED).build()

        return try {
            ResponseEntity.ok(RefreshResponse(refreshSession.execute(sessionId)))
        } catch (_: SessionNotFoundException) {
            ResponseEntity.status(HttpStatus.UNAUTHORIZED).build()
        } catch (_: SessionExpiredException) {
            ResponseEntity.status(HttpStatus.UNAUTHORIZED).build()
        }
    }

    private fun constantTimeEquals(a: String, b: String): Boolean =
        java.security.MessageDigest.isEqual(a.toByteArray(), b.toByteArray())
}
```

```kotlin
package io.codehunters.authbff.keycloak

import java.time.Instant
import org.springframework.security.oauth2.jwt.JwtDecoder
import org.springframework.security.oauth2.jwt.JwtException

class InvalidLogoutTokenException(message: String) : RuntimeException(message)

data class LogoutClaims(
    val keycloakSessionId: String,
    val jti: String,
    val expiresAt: Instant,
)

/**
 * Validates Keycloak's backchannel logout token. The `events` check matters: without
 * it, any valid token from the realm — including an ID token — could be replayed to
 * terminate arbitrary sessions.
 */
class LogoutTokenValidator(private val decoder: JwtDecoder) {

    fun validate(rawToken: String): LogoutClaims {
        val jwt = try {
            decoder.decode(rawToken)
        } catch (e: JwtException) {
            throw InvalidLogoutTokenException("logout token failed validation: ${e.message}")
        }

        val events = jwt.getClaim<Map<String, Any>>("events")
            ?: throw InvalidLogoutTokenException("logout token has no events claim")
        if (!events.containsKey(BACKCHANNEL_EVENT)) {
            throw InvalidLogoutTokenException("logout token is not a backchannel logout event")
        }

        val sid = jwt.getClaimAsString("sid")
            ?: throw InvalidLogoutTokenException("logout token has no sid claim")
        val jti = jwt.getClaimAsString("jti")
            ?: throw InvalidLogoutTokenException("logout token has no jti claim")
        val expiresAt = jwt.expiresAt
            ?: throw InvalidLogoutTokenException("logout token has no exp claim")

        return LogoutClaims(sid, jti, expiresAt)
    }

    private companion object {
        const val BACKCHANNEL_EVENT = "http://schemas.openid.net/event/backchannel-logout"
    }
}
```

```kotlin
package io.codehunters.authbff.web

import io.codehunters.authbff.keycloak.InvalidLogoutTokenException
import io.codehunters.authbff.keycloak.LogoutTokenValidator
import io.codehunters.authbff.session.port.ClockPort
import io.codehunters.authbff.session.port.SessionStorePort
import io.codehunters.authbff.session.usecase.RevokeByKeycloakSessionId
import java.time.Duration
import org.slf4j.LoggerFactory
import org.springframework.http.ResponseEntity
import org.springframework.web.bind.annotation.PostMapping
import org.springframework.web.bind.annotation.RequestMapping
import org.springframework.web.bind.annotation.RequestParam
import org.springframework.web.bind.annotation.ResponseBody

@ResponseBody
@RequestMapping("/auth/backchannel-logout")
class BackchannelLogoutController(
    private val validator: LogoutTokenValidator,
    private val revoke: RevokeByKeycloakSessionId,
    private val store: SessionStorePort,
    private val clock: ClockPort,
) {
    private val log = LoggerFactory.getLogger(javaClass)

    @PostMapping
    fun logout(@RequestParam("logout_token") logoutToken: String): ResponseEntity<Void> {
        val claims = try {
            validator.validate(logoutToken)
        } catch (e: InvalidLogoutTokenException) {
            log.warn("rejected backchannel logout: {}", e.message)
            return ResponseEntity.badRequest().build()
        }

        val ttl = Duration.between(clock.now(), claims.expiresAt)
        if (ttl.isNegative || !store.claimLogoutToken(claims.jti, ttl)) {
            log.warn("rejected replayed or expired backchannel logout token")
            return ResponseEntity.badRequest().build()
        }

        revoke.execute(claims.keycloakSessionId)
        return ResponseEntity.ok().build()
    }
}
```

## Manual Verification Before Handing Off to the Gateway Plan

The plugin plan assumes a Keycloak realm and a populated Redis. Confirm both by hand:

1. Create the `gateway-bff` confidential client in the `forgeos` realm with the redirect and backchannel-logout URLs above.
2. Start Keycloak, Redis and `auth-bff`.
3. Open `http://localhost:8086/auth/login/keycloak` in a browser, log in.
4. Confirm the browser holds a `sid` cookie and **no** token: check DevTools → Application → Cookies.
5. Confirm the session exists with the exact contract:
   ```bash
   redis-cli -a "$REDIS_PASSWORD" --scan --pattern 'v1:session:*'
   redis-cli -a "$REDIS_PASSWORD" HGETALL v1:session:<sid>
   ```
   All nine fields must be present, `refresh_token_enc` must start with `k1.`.
6. Record the realm's **SSO Session Max** and **Access Token Lifespan**; these settle the two open items in the spec (`abs_exp` and the refresh threshold).

## Open Items Carried From the Spec

- `session.absolute-lifetime` is set to `10h` as a placeholder for the realm's actual *SSO Session Max*. Step 6 above produces the real value; change the default in `application.yml` once known.
- `/internal/**` currently uses a shared secret. If the deployment topology provides mTLS between the gateway and this service, replace the secret check with client-certificate verification — the controller's guard clause is the single place to change.
